# CAMPAR SGC Digital v0.6

Versión depurada de la interfaz con enfoque en claridad operativa y uso ejecutivo.

## Cambios clave
- Navegación reducida a 7 módulos principales.
- Diseño más sobrio y formal en todo el entorno.
- Módulo de inventario ajustado para dar más foco a los dos aserraderos y al concentrado total.
- Tarjeta de "Producto seleccionado" reducida de tamaño para no restar protagonismo a la información crítica.
- KPI superiores centrados sólo en piezas limpias de Cosme, Duma y concentrado total.

## Estructura
- `index.html` contiene estilos y lógica embebidos, listo para despliegue sencillo.
- `assets/logo-campar.png` contiene el logotipo institucional.
- `docs/` incluye accesos rápidos a documentación principal.
